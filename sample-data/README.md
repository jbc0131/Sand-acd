# Sample data (fictional)

Everything in this folder is invented for a software demo. It does not describe any real plant and must not be used for operations.

- `SAMPLE-E-001_revA_Bus1A_one_line.pdf`, `SAMPLE-E-002_revA_MCC-1A1_detail.pdf`, `SAMPLE-E-003_revB_EDG-1A_elementary.pdf` — three fictional drawings for the diagram upload (needs ANTHROPIC_API_KEY); the matching PNGs are the pre-rendered page images the seed uses
- `SAMPLE_Bus1A_OM_Manual.pdf` — 11-page O&M manual for the O & M Manuals card
- `SAMPLE_asset_register.csv` — asset register for the Asset Database card
- `SAMPLE_historian_export.csv` — historian export for the Telemetry card

Regenerate with `npm run sample:files`.
